### 📌 Featured

| Project | What it is |
| --- | --- |
| **[pulse-trace](https://github.com/morenolabs/pulse-trace)** | An EDA/GSR response monitor for the Arduino UNO R4 WiFi. Firmware streams skin conductance over USB serial; a browser app reads it through Web Serial, runs a gated calibration sequence, and measures event responses. Explicitly *not* a lie detector. |
| **[eclipse-control-de26](https://github.com/morenolabs/eclipse-control-de26)** | A SCADA-style operations display for the partial solar eclipse over Germany on 12 August 2026. Every number computed locally from VSOP87/NOVAS-derived ephemerides — no backend, no API. |
